ReverseAI

Find the AI, prompt, model, tools & settings behind an image, a text, a website or a chatbot API.

  • Image → generator, exact prompt / negative prompt / seed / model / LoRAs from metadata, C2PA Content Credentials.
  • Text → which chatbot wrote it (citation tokens, self-ID, style), hidden Unicode payloads, AI-likelihood.
  • URL → AI chat widgets, AI APIs, AI site-builders, llms.txt, AI-crawler rules, agent cards & skills, leaked prompts.
  • App name → leaked system prompts, tool definitions and skills from public GitHub collections.

Fingerprints the model behind any OpenAI-compatible /chat/completions API and tests whether it reveals its system prompt and tools. Only for APIs you own or may test.

Optional. Used for "Ask my LLM" (visual / textual reverse-prompt) and as the default for Endpoint probe. Any OpenAI-compatible API works. The key is kept in this browser's localStorage and only sent to your local ReverseAI server, which forwards it to the provider.
